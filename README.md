# Repositório de referências — Trabalho de Graduação

Repositório público de apoio ao Trabalho de Graduação do curso Superior de Tecnologia em Ciência de Dados para Negócios.

## Objetivo

Organizar e documentar as fontes bibliográficas e técnicas citadas no trabalho, facilitando a conferência de autoria, título, dados editoriais, DOI e endereços oficiais de consulta.

Este repositório é um **índice de rastreabilidade bibliográfica**. Ele não substitui as referências apresentadas no TG e não implica que todos os materiais estejam hospedados aqui.

## Estrutura

- `referencias/referencias-bibliograficas.md`: referências organizadas em formato próximo ao padrão ABNT.
- `referencias/referencias.bib`: registros BibTeX para gerenciadores bibliográficos.
- `referencias/indice-de-fontes.md`: finalidade e endereço de consulta de cada fonte.
- `evidencias/livros-e-artigos.md`: livros e artigos científicos, com DOI e opções de acesso.
- `evidencias/documentacoes-tecnicas.md`: documentação oficial das ferramentas.
- `evidencias/documentos-academicos-e-internos.md`: documentos institucionais e fontes internas, cuja disponibilização depende de autorização.

## Critérios de organização

1. Priorizar páginas oficiais de editoras, universidades, periódicos, organizações e projetos de software.
2. Informar DOI quando identificado.
3. Indicar PDFs somente quando houver uma versão de acesso aberto ou um endereço institucional confiável.
4. Não redistribuir livros, artigos ou documentos protegidos por direitos autorais sem autorização.
5. Não publicar bases transacionais, relatórios internos ou dados comerciais da Berto Ferramentas.
6. Distinguir a existência de uma referência bibliográfica da confirmação de que seu conteúdo foi efetivamente consultado. A versão final do TG deve conter apenas fontes realmente utilizadas.

## Observações importantes

- Alguns livros são comercializados ou disponibilizados por acesso institucional; seus registros e páginas oficiais são indicados, mas o PDF integral não é reproduzido.
- Os documentos internos da Berto Ferramentas e o Manual do TG devem ser adicionados apenas se houver autorização e se a instituição permitir sua divulgação pública.
- Os endereços e metadados foram organizados a partir das referências fornecidas para o TG. Recomenda-se conferir os dados editoriais finais com a edição efetivamente consultada.
- A data de acesso indicada nas referências bibliográficas corresponde a **4 nov. 2026**, conforme a lista fornecida pelo autor.
